The game

Time trials, team trials, regular stages and mountain climbs make up the competition. Repeated presses build speed, but drain the rider’s strength; letting that run out slows the bike.[2]

Development

Frédéric Nespoulous programmed the ExEn version, with Eric Thommerot producing it.[3]
